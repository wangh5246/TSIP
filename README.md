# TSIP Heatmap Source Release

This directory contains one publishable source tree only:
[`TSIP_heatmap_version/`](TSIP_heatmap_version/).

Historical method snapshots, experiment outputs, paper-build files, local data,
and internal notes have been removed. The retained implementation is the final
V4-paper protocol source, its runtime, and the paper-k6 development proving
artifacts required to inspect or reproduce the included relation.

Before publishing, move `TSIP_heatmap_version/` into its own Git repository and
choose an OSI-approved license. No license is included yet because the project
owner has not selected one.
