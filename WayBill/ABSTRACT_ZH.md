# 中文摘要

减少披露的道路使用收费可通过本地计费和密码学证明避免上传原始轨迹，但已提交记录的正确性并不保证所有收费区间或周期均被提交。本文提出 WayBill，一种条件性结算设计：进程隔离的接收器签名组件封存采集侧提供的定位单元标签、单调里程和由起点状态按策略推导的标签可采纳位；车辆以零知识方式证明每个已上报区间遵循承诺费率，或按最高费率回退计费；月末再将签名里程中未被非重叠已接收周期覆盖的部分按同一最高费率结算。在接收器证明、证明系统和月度里程均正确且月结成功的条件下，我们证明回退或隐瞒整个周期不能使账单低于采集侧接受、接收器封存标签对应的参考账单。这一性质等价于“最高费率基线减去经验证折扣”，不证明物理位置真实，也不覆盖采集组件或接收器失陷、里程篡改和 GNSS 转发。V6 原型的一次可追溯 25 定位点 Groth16 运行包含 246,255 个约束和 22 个公开信号，生成 803 字节 JSON 证明编码；证明与验证时间分别为 3.65 秒和 217 毫秒。TestClient/SQLite 端点逻辑收据还记录了重放拒绝、公开信号篡改拒绝和月末补收。上述数据仅验证一条规范执行路径；四数据集的公式级计费敏感性、电路扩展性、有限单元/轨迹位移、元数据关联和进程内处理器行为仍待新的不可变发布与正式 M4 严格聚合验证。

**关键词：** 道路使用收费；披露最小化；零知识证明；可信感知；条件性结算；全球导航卫星系统
