# 五数据集 N=1000 输入与用途

## 数据集

- T-Drive
- GeoLife
- Porto
- Rome
- Synthetic

## 两条实验用途

### 原始输入效用评估

固定公平效用和逐数据集优化均读取原始五数据集 1000-user files。主比较固定 `epsilon=5.0`、`tau=2.0`，10 rounds、3 seeds，使用 top-50 Jaccard，并同时保留 RMSE、FRR 和 MRR 相关 receipt。

### Docker clean protocol

协议 smoke 与 paper-scale clean matrix 设置 `TSIP_SAFE_PROTOCOL_TRAJECTORY=1`，生成满足状态约束的 protocol trajectory，以隔离 Groth16、Docker 路由、聚合、重构和 DP pipeline 是否可执行。它不替换原始输入的效用实验，也不能被描述为真实数据轨迹上的 security guarantee。

## 数据集扩充历史

2026-07-07 审阅指出两真实数据集加 derived subsets 不足以支撑 4 到 5 数据集要求。2026-07-09 后实验集扩展为 T-Drive、GeoLife、Porto、Rome 和 Synthetic；旧的两数据集判断已失效。

## 使用约束

- 论文必须注明 Synthetic 是合成集，不能与四个真实数据源混称为五个真实数据集。
- 根级 `DATA_NOTICE.md` 是数据来源、许可、下载指引与本地变换的事实源；真实数据必须由复现者从官方源自行获取并接受条款。
- 同一表中比较方法时使用同一数据、seed、round 和隐私参数；per-dataset tuned 结果只能作为补充上界。

## 官方来源与发布边界

- T-Drive：Microsoft Research Asia；官方 landing page 与 T-Drive user guide；MSR-LA 限非商业研究并禁止分发数据或 derivative works；指南要求 GIS 2010 与 KDD 2011 两篇引用。
- GeoLife：Microsoft Research Asia；官方 tools page 与 version 1.3 guide；MSR-LA 同样禁止再分发；指南要求 UbiComp 2008、WWW 2009 与 IEEE Data Engineering Bulletin 2010 三篇引用。
- Porto：UCI Machine Learning Repository，DOI `10.24432/C55W25`，CC BY 4.0；尽管许可允许署名分享，项目仍按统一策略不发布 raw/row-level prepared trajectories。
- Rome：CRAWDAD roma/taxi v. 2014-07-17，DOI `10.15783/C7QC7M`；遵循 cite contributors、不得去匿名化、不得重分享并引导用户回官方源的指引。
- Synthetic：`prepare_five_dataset_heatmap_inputs.py` 固定 seed 20260709 的 clustered random walk；是否发布行级生成结果仍取决于作者选择项目 license。

## 本地变换与仓库内容

- T-Drive、GeoLife、Rome 以 120-second gap 切分，使用局部投影、100 m cell、100 x 100 grid，生成 non-overlapping 10-window records，并从 1000 个 source records 无 bootstrap 取样。
- Porto 先由 `runtime/script/prepare_eval_datasets.py` 解析 UCI `train.csv.zip` 的 15-second POLYLINE，再由 Heatmap preparer 生成 1000-user/10-window 输入，无 bootstrap。
- `.gitignore` 排除四真实数据集派生 JSONL 与 period directories；仓库只保留生成/预处理代码、非行级 manifest、聚合 receipts、表和图。
