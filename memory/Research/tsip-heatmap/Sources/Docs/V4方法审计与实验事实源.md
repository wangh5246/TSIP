## 权威顺序

1. 单元 `status.json` 决定该 dataset-seed 是否通过。
2. `launch_status.json` 汇总矩阵，但运行被外部终止时可能残留 `state=running`，因此还要核对 PID、mtime 和 proof counters。
3. Docker `healthy` 只证明服务 health endpoint 可达，不证明 client round 正在执行。
4. `experiment-report.md` 是 2026-07-10 启动前快照，其中“paper-scale launch was not started”已过期，不能描述当前状态。
