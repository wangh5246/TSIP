## 权威顺序

1. 单元 `status.json` 决定该 dataset-seed 是否通过。
2. `launch_status.json` 汇总执行矩阵，但不能单独支撑吞吐、时间或完整功能总账。
3. `aggregate_summary.json` 严格绑定 manifest、launcher 和 15 个互异 unit receipt hashes，决定 scale 统计能否进入论文。
4. `paper_evidence.json` 只在 strict aggregate 合同全部通过后把 `scale.status` 升级为 `verified`。
5. Docker `healthy` 只证明服务 health endpoint 可达，不证明 client round 正在执行。
6. `experiment-report.md` 是 2026-07-10 启动前快照，其中“paper-scale launch was not started”已过期，不能描述当前状态。
