# 论文实验复现细节补强 2026-07-22

## 结论

审稿人可能追问的三项实验细节已经闭合并进入论文。RQ1 明确为 12 次载荷绑定负向尝试。RQ3 改为用户互斥训练/测试划分并重跑四个真实数据集。图 5 明确给出 generic external ESA adapter 的采样、阈值和去偏规则。大规模 Groth16 矩阵与固定效用结果没有重跑或改变。

## RQ1 payload mutation harness

- Harness 对一个 canonical passing fixture 执行恰好 12 次 deterministic negative attempts，每个 mutation 尝试一次。
- 两次为 proof 或 public-signal context substitution。
- 五次为 private-witness substitution，分别覆盖 hidden primary、A-share digest、R-share digest、双 share digest 和 private context commitment。
- 五次为 post-proof route mutation，分别覆盖 A share、R share、cross-route、route context 和 blob hash。
- 12 次全部在 proof、transport 或 aggregation validation 被拒绝。
- 22-check static gate 还包含五个 state/identity negatives 和五个 passing compatibility cases。

## RQ3 classifier 与严格划分

- 所有已报告分类器均使用 training-set `StandardScaler` 加 sklearn MLP。
- MLP 为 32/16 两个 ReLU hidden layers，Adam，L2 系数 `1e-4`，learning rate `1e-3`，15% early-stopping validation。
- Synthetic feature ablation 保持 label-stratified 70/30 sample split。每个 seed 为 8,750 train 和 3,750 test samples，iteration cap 150。
- Real session linking 改为 user-disjoint 70/30 split。每个 seed 先分 700 train users 和 300 unseen test users，再在各分区内分别生成 negative partners。
- 每个用户生成一个 same-user pair 和一个 cross-user pair。每个 seed 为 1,400 balanced train pairs 和 600 balanced test pairs，不共享用户。
- 四个真实输入的 dense hourly bins 为 T-Drive 17、GeoLife 18、Porto 11、Rome 8。

## RQ3 精确结果

三种子 7、11、19 的 mean AUC 加 sample standard deviation 为：

| Dataset | Session-linking AUC |
|---|---:|
| T-Drive | 0.7434 +/- 0.0138 |
| GeoLife | 0.7491 +/- 0.0064 |
| Porto | 0.7268 +/- 0.0261 |
| Rome | 0.7316 +/- 0.0233 |

四个数据集均稳定高于 random AUC。Active-period AUC 范围为 0.9987 到 0.9999。该结果只证明 Shuffler-visible timing 和 chain metadata 存在 residual linkability，不是 coordinate recovery。

## 图 5 external ESA adapter 规则

- 对 submitted cell，以 `p = 1 - exp(-epsilon)` 报告该 cell，否则从 `D = 10,000` 均匀采样 dummy cell。
- 对 N 个 reports 做 shuffle 后按 cell 计数。
- raw count 小于 3 的 cell 被过滤为 0。
- 令 `q = (1-p)/D`，输出 `max(0, (c-Nq)/(p-q))`。
- Adapter 不执行 trajectory、cross-round 或 malicious-report rejection，因此 A1 valid-range reports 不会被拒绝。
- 图 5 中 SHTPC 的 post-admission threshold 为 2。External ESA 的 raw-count threshold 为 3。两者不能混写成共享 `tau=2`。
