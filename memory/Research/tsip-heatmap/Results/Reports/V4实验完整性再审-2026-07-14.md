# V4 实验完整性再审 2026-07-14

## 结论

当前规格定义的实验已经完成，现有 scoped claims 不需要新增或重跑实验。该结论不等于论文无法被质疑。可预见的审稿问题应通过准确披露、限制主张和改善实验设置描述处理，而不能用“全部最优”掩盖。

- 13 个 timing-eligible units 为 1.000 +/- 0.069 proofs/s、4.183 +/- 0.248 h/单元。Rome/101 与 Synthetic/101 仅因 host suspension 排除 timing。
- Evidence builder、manuscript checker、strict summarizer 和 publication figure 合计 237 tests passed，最终稿件合同为 0 issues。
