## M1 记录区

- 当前状态：`verified`；组合 SSOT 为 `experiments/waybill_m1/v1/gate_summary.json`。
- 数据门禁：4 数据集 226 periods、0 reject；3 个 outage α × 5 seeds 形成 3390
  paired rows。四数据集绝对/相对 P95 surcharge 均低于 V5；最大 undercharge、最大
  withholding advantage 与 parking V6 fee 均为 0。
- 统计门禁：按 226 period 聚类、5000 次 bootstrap 的 paired median improvement
  为 70500 cents，95% CI `[70068, 70680]`；1582 条 odometer ±0.5%/±1%/±2%
  sensitivity 均满足声明的 revenue/fairness bounds。
- 电路门禁：`SettlementPeriodV6(25,8,6)` 为 240,258 constraints；真实 proof
  验证成功，22/22 public signals 与 Python 一致，非零 profile commitment 被电路约束。
- 服务门禁：canonical proof=200、replay=409、tampered signal=400、month attestation
  与 close=200；仅对 600 m unaccounted distance 收取 3000 cents。endpoint receipt
  同时记录当前 policy、V6 settlement、runner 与 charger code hashes。
- 修复审计：两份 V6 tariff artifact 的 declared root 已与 Poseidon depth-8 重算 root、
  profile 和 public signal 统一；loader 新增 declared root/max-rate fail-closed 测试。
- 证据边界：结论依赖 authenticated、monotone、calibrated odometer；不是 receiver/
  odometer field certification，也不是统一现实税制的财政估计。

## M3 记录区

- 当前状态：`verified`；SSOT 为 `experiments/waybill_m3/v1/summary.json`，逐实例证书为
  `bound_receipts.jsonl`。
- 冻结模型 `e3-v6-fixed-odo/v1` 共 24 个 dataset/stratum/bucket 实例，24/24
  certified；100/50/25/10 m 全部 `LB=UB`、gap=0、无 timeout，strict feasible
  checker、`LB≤UB_rect≤UB_ind` 与 gap gate 全通过。
- 独立原整数域 oracle 为 `LB=0, OPT=90, UB=90`，刻意包含 non-center optimum，
  防止 oracle 退化成 center-only。
- 当前 summary 记录 Python/platform/CPU、实际命令、pure-Python solver backend、串行
  执行语义、runtime/memory/timeout 与代码/输入/artifact hashes。
- 旧 Rome `0.464→0.295` 仅为 legacy bucket sensitivity，不是 certified bound；旧
  `648m→361m` 投影被冻结 SSOT 以 `ODO_BINDING` 拒绝，不能横向比较。
- 证据边界：只认证当前冻结模型与 24 个实例；M3 legacy-adapter tariff 不是 M2
  10,000-cell root，也不是现实每米计费。无合法 UB 的新增实例必须降级为
  heuristic/unresolved。
