# 服务器正式实验就绪性审计（2026-07-15）

## 审计结论

**No-go：当前不能直接启动论文级正式服务器实验。** M0–M3 的方法正确性门禁已经
关闭，但代码冻结、Linux 复现环境、完整数据、正式矩阵编排和目标主机验收尚未关闭。
现状可支持继续开发，不支持把服务器输出直接作为正式论文证据。

获批的正式实验规格为 [[Experiments/M4-服务器正式大规模实验]]。本报告只记录当前
事实和关闭条件，不把计划写成已经完成。

## 目标资源下限

- Linux x86_64；建议关闭会造成不可解释抖动的自动超卖；
- 单个 setup/prove job 至少 32 GiB RAM；并发按每个 n=200 proof 预留 8 GiB
  观测上限加安全余量；
- 正式工作目录至少 100 GiB，raw data/object-store cache 与实验输出分离；
- depth/fixes latency 主表采用隔离 job；并发实验独立运行，不能混入主 latency；
- PTAU 只从固定来源获取并验证精确 bytes/BLAKE2b，不通过 Git 传输。
